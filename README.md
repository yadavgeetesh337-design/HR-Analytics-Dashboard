
# 📊 HR Analytics Dashboard (Excel)

An interactive **HR Analytics Dashboard** built in **Microsoft Excel** to analyze employee attrition, workforce demographics, and HR performance metrics. This dashboard helps HR professionals identify attrition patterns and make data-driven decisions for improving employee retention.

---

## 🎯 Project Objective

The objective of this project is to analyze HR data and provide meaningful insights into employee attrition, job satisfaction, and workforce distribution through an interactive Excel dashboard.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Dashboard Design

---

## 📈 Key Performance Indicators (KPIs)

- 👥 Total Employees
- ✅ Active Employees
- ❌ Employee Attrition
- 📉 Attrition Rate
- 🎂 Average Age
- ⭐ Job Satisfaction Rating

---

## 📊 Dashboard Features

- Employee distribution by Gender
- Education-wise Attrition
- Department-wise Attrition
- Job Role-wise Attrition
- Age Group Analysis
- Marital Status Analysis
- Interactive Filters (Slicers)
- Dynamic KPI Cards
